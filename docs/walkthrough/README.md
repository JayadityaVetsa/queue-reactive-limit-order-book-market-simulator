# Interactive strategy walkthroughs

Download these HTML files and open them in a browser. GitHub displays their source rather than running them. The charts load a pinned visualization library, so internet access is required.

- [Read the order book](read-the-order-book.html): switch among buyer-heavy, balanced and seller-heavy depth, then compare the frozen model's forecast with the cost hurdle.
- [Follow one trade](one-trade-explained.html): move from entry to event 20 and change the illustrative outcome between rising, falling and unchanged prices. The display distinguishes marked P&L from realized net P&L.

The first walkthrough uses illustrative book quantities and the actual fitted zero-latency forecast coefficients. The second uses a hypothetical price path to explain accounting; it is not a backtest or a promised outcome. Prices and fees are expressed in ticks, not dollars.

For the complete assumptions and evaluation results, see [the strategy explanation](../ALPHA_STRATEGY.md) and [the report](../../reports/alpha/REPORT.md).
